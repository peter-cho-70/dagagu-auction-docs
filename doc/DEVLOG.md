이 프로젝트는 대전 다가구주택 경매 물건을 법원경매정보 사이트에서 수작업으로 리스트업하고, 보스옥션(대장옥션)에서 상세 자료를 받아 권리분석 리포트를 만들던 반복 작업을 프로그램으로 옮기면서 시작됐다.

- **추가/변경**: (사용자 요청) 왼쪽에 **즐겨찾기(1차 선별) 사이드바** 추가 — `localStorage`에 저장, "전체 / 즐겨찾기만" 필터 토글.

- **추가/변경**: (사용자 요청) 디자인 폴리시 — 대장옥션(보스옥션) UI를 참고해 헤더 브랜드 마크, 최저가 퍼센트 색상 배지(50% 미만 빨강 / 중간 금색 / 100%(신건) 초록), 경매사이트 선택 카드 강조(선택 시 테두리+배경), 버튼·배지 전반 다듬음.
- **버그 수정**: 법원 사이트(WebSquare 프레임워크)의 검색/확인 버튼이 그림자(shadow) DOM류로 렌더링돼 일반 `querySelectorAll`·텍스트 매칭·일반 클릭으로 안 잡히던 문제 → 접근성 스냅샷에서 ref를 그때그때 찾아 `force:true` 옵션으로 클릭하도록 수정.
- **버그 수정**: 1단계 스크립트가 각 사건 블록 끝에 오는 "빈 3칸 행"(용도/가격/상태를 담는 행과 셀 개수가 똑같음)을 실제 데이터 행으로 잘못 인식해, 방금 채운 값을 빈 문자열로 덮어쓰던 버그 → 첫 칸이 비어있지 않을 때, 그리고 아직 값이 채워지지 않았을 때만 채우도록 조건 수정.
- **버그 수정**: 보스옥션 문서 텍스트를 추출하면 사이드바 메뉴 텍스트(약 700자)만 잡히고 실제 내용이 안 나오던 문제 → 실제 내용이 최상위 문서가 아니라 같은 출처의 `iframe`(`pop_view*_ifm.html`) 안에 있었음을 발견. `contentDocument`로 직접 들어가 텍스트를 뽑도록 수정(스크린샷은 iframe 포함 렌더링이라 원래부터 정상이었음). 같은 문서 링크가 화면에 중복 렌더링돼 셀렉터가 여러 개 걸리던 문제는 `nth=0`으로 첫 번째(보이는) 요소만 선택하도록 수정.
- **버그 수정**: 서버가 ego-browser 자식 프로세스의 출력(JSON 요약)을 stdout에서만 찾다가, 상황에 따라(업데이트 알림 유무 등) 결과가 stderr로 나올 때 파싱이 실패하던 문제 → stdout+stderr를 합쳐서 JSON 블록을 찾도록 수정.
- **버그 수정**: 패널을 상시 도킹 패널로 바꾸면서 내부 스크롤이 전혀 안 되던 문제(`flex:1`이 걸릴 flex 컨테이너가 중간에 없었음) → 중간 래퍼(`#panelFilled`)에 `display:flex; flex-direction:column; height:100%`를 추가해, 패널 헤더(제목·탭)는 고정되고 본문만 스크롤되도록 구조 수정.
- **이슈/막힌 점**: 법원 사이트(기일입찰 검색)는 매각기일 조회 범위를 **현재일자 기준 2주로 강제 제한**함 — 더 넓게 조회하려는 시도는 사이트 자체 경고창("검색기간은 현재일자로부터 2주 이내 입니다")으로 막힘. 구조적 제약으로 받아들이고 기본값 그대로 사용(진행 중인 사건은 항상 2주 내 다음 기일이 잡혀 있어, 이 2주 창이 사실상 "현재 활성 사건 전체"와 같다는 논리).
- **이슈/막힌 점**: 보스옥션 로그인 세션은 1시간 미사용 시 자동 로그아웃됨 — 등기(건물/토지)를 받으려면 그때마다 ego-lite 브라우저에서 재로그인 필요. 이메일·비밀번호 입력이 필요한 본인 확인 단계라 `task.handOff()`로 사용자에게 넘기고, 로그인 완료 알림을 받으면 같은 브라우저 세션을 이어받아 계속하는 방식으로 처리(실제로 2026타경600076의 등기 2종을 이 방식으로 성공적으로 수령).
