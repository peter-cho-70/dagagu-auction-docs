# 대전 다가구 경매 파이프라인 — 설계 문서(PRD)

- 작성일: 2026.10.23 (2026.10.24 갱신)
- 작성: Claude (Peter 요청 기반)
- 상태: Phase 1·2 구현 완료, Phase 3(보스옥션 자료 가져오기) 구현 완료, Phase 4(자동 분석)는 다음 단계

## 1. 목표

대전 지방 다가구주택 경매 물건을 조사하는 반복 업무를 프로그램으로 자동화한다. 지금까지 이 대화에서 수작업으로 했던 과정(법원 사이트 리스트업 → 전문 경매사이트에서 상세 자료 확인 → 권리분석 리포트 작성)을 **3단계 로컬 웹앱**으로 재구성한다.

## 2. 전체 흐름

```
[1단계: 대법원 법원경매정보]          [2단계: 사이트·자료 선택]       [3단계: 다운로드·분석]
대전 다가구 물건 전체 조회      →      리스트에서 물건 클릭      →     경매사이트 선택(보스옥션 등)
(신건+유찰 전체, 날짜 제한 없음)        → 우측 패널 열림               자료 체크박스 선택
네이버지도 링크 자동 생성                                              다운로드 → 로컬 저장 → 분석 리포트
```

### 1단계 — 리스트업 (법원경매정보, 무료, 로그인 불필요)
- 대전광역시 + 용도(건물 > 주거용건물 > 다가구주택) 고정 필터
- 입찰구분 "전체", 매각기일 범위를 오늘 ~ +N일(기본 90일)로 넓게 잡아 **신건·유찰 전체**를 포착 (법원 사이트는 진행 중인 사건이면 항상 다음 기일이 잡혀 있으므로, 충분히 넓은 날짜 범위가 사실상 "전체"와 같음)
- 각 행: 사건번호, 소재지, 용도, 감정가, 최저가, 유찰횟수, 담당계, 매각기일
- 소재지 주소를 그대로 네이버지도 검색 링크로 변환: `https://map.naver.com/p/search/<URL인코딩된 주소>`
- 결과를 `data/daejeon-dagagu-YYYYMMDD.json`에 저장

### 2단계 — 물건 선택 → 경매사이트 선택 (로컬 웹앱)
- `localhost:4600`에서 1단계 결과를 표로 표시 (지도 링크 포함)
- 행 클릭 시 우측 패널 오픈:
  - 경매사이트 선택: 라디오 버튼 (초기값: 보스옥션만 활성화, 지지옥션/굿옥션/스피드옥션은 "준비중"으로 비활성 표시 — UI 구조만 미리 만들어 둠)
  - 자료 체크박스: 등기(건물)·등기(토지)·감정평가서·매각물건명세서·현황조사서·문건/송달내역 (기본 전체 선택)

### 3단계 — 다운로드 → 로컬 저장 → 분석
- "다운로드 시작" 클릭 → 백엔드가 ego-browser 스크립트를 실행해 선택된 사이트에서 선택된 자료를 가져옴
- 로그인이 필요한 자료(등기 등)는 ego-lite 브라우저 프로필에 **이미 로그인된 세션이 있으면 그대로 재사용**, 없으면 이전 대화처럼 핸드오프로 사용자에게 로그인을 요청
- 저장 위치: `downloads/<사건번호>/` 폴더에 원본 자료(PDF/스크린샷) + `summary.json`(핵심 수치 추출본)
- 분석 리포트(지난 두 번 작업에서 만든 것과 같은 HTML 뷰어)는 이번 Phase에서는 **수동 트리거**로 남겨둠 — "리포트 생성" 버튼을 누르면 Claude Code 세션에 분석을 요청하는 안내가 뜨는 정도로 시작하고, 완전 자동 리포트 생성은 Phase 4로 미룬다 (사건마다 리스크 해석이 달라 단순 템플릿화가 어려움).

## 3. 기술 스택

- **자동화**: ego-browser (`ego-browser nodejs`) — 이미 설치되어 있고 이 대화에서 검증됨. 사람의 로그인 핸드오프와 자연스럽게 연동됨.
- **로컬 서버**: Node.js 내장 `http` 모듈만 사용 (외부 의존성 없음 — 설치 없이 바로 실행 가능)
- **프런트엔드**: 단일 `public/index.html` (바닐라 JS, 지난 리포트들과 같은 디자인 톤)
- **데이터**: JSON 파일 (벡터DB나 외부 서버 없음 — MyRemember와 동일하게 로컬 우선)

## 5. 로컬 저장 위치와 개인정보 처리

- 다운로드한 원본 자료(등기부, 매각물건명세서 등)는 **개인정보(소유자·임차인 실명)가 포함**될 수 있으므로 `downloads/`는 `.gitignore`에 포함하고, 이 프로젝트를 깃 저장소로 만들거나 외부에 공유할 경우 반드시 제외한다.
- 분석 리포트(사람이 보는 최종본)는 지난 두 번의 작업처럼 이름을 익명화한 버전만 작성한다. 원본 파일과 익명화된 리포트를 분리해서 저장한다 (`downloads/<사건번호>/raw/` vs `downloads/<사건번호>/report/`).

## 6. 범위 밖 (Phase 4+)

- 지지옥션·굿옥션·스피드옥션 등 추가 사이트 연동 (사이트별 UI가 달라 각각 별도 작업 필요)
- 완전 자동 리포트 생성(지금은 Claude Code 세션에서 제가 직접 작성)
- 배당표 자동 계산, AI 권리분석 교차검증
- 여러 사건 동시 다운로드(배치 처리) — 사이트 이용약관상 과도한 자동 요청은 피해야 하므로 신중히 설계 필요

## 7. 실행 방법

```bash
# 1단계: 리스트 갱신
ego-browser nodejs < scripts/scrape-daejeon.mjs

# 2단계: 로컬 웹앱 실행
node server/server.mjs
# → http://localhost:4600 접속
```
